## Selected projects

### Auris — real-time sound classification and drone detection
*B.Sc. final project · team of two · 2025–2026*

A 13-class, multi-label audio classifier for general sound events, including drones. We fine-tuned an AudioSet-pretrained EfficientAT model on log-Mel spectrograms and built a dataset review dashboard to track recordings, labels and data splits.

- **Evaluation:** 89.8% macro-F1 on a 3,043-window test set.
- **Deployment:** Live microphone inference on desktop and Raspberry Pi 4.
- **Stack:** Python, PyTorch, audio DSP, dataset curation.

### License plate recognition
*Computer vision course project · 2026*

A video pipeline for detecting and reading Israeli license plates. It combines YOLO11m detection, ByteTrack tracking, character segmentation and a CNN-based digit reader, then aggregates predictions across frames.

- **Evaluation:** 0.965 mAP@0.5 for plate detection.
- **Stack:** Python, OpenCV, YOLO11m, ByteTrack, CNN-based OCR.
